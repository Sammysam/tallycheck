# Getting help with TallyCheck

## Using the app

- **User guide:** [docs/user-guide/TallyCheck-User-Guide.pdf](docs/user-guide/TallyCheck-User-Guide.pdf)
  covers setup, invoices, bills, banking, reports, payroll, backups and the Claude connector.
- **In the app:** Help → About TallyCheck shows the version you are running.
- **Forgotten password or username:** use "Forgot password?" or "Forgot username?" on the
  sign-in screen with your recovery key (or Windows sign-in on the main PC).

## Questions, problems and ideas

| You want to… | Where |
|---|---|
| Report a bug | [Open a bug report](https://github.com/Sammysam/tallycheck/issues/new?template=bug_report.md) |
| Suggest a feature | [Open a feature request](https://github.com/Sammysam/tallycheck/issues/new?template=feature_request.md) |
| Report a security problem | Privately, as described in [SECURITY.md](SECURITY.md) — never in a public issue |
| Ask about sales, licences, a demo or anything else | Email **info@tallycheck.io**, or [request a demo](https://tallycheck.io/demo) |

Before opening an issue, search the existing ones; add to an open issue rather than starting a
new one. Include the TallyCheck version (Help → About TallyCheck), Windows or macOS version and the steps
to reproduce the problem.

**Never attach real company, customer, employee or payroll data**, backups or screenshots
showing them. A made-up company is enough to show a problem.

## What to expect

TallyCheck is maintained by a small team at Cenango (Pvt) Ltd. We read every issue, but cannot
promise a reply time for free support. Security reports are answered within 3 working days.
