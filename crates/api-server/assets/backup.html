Backup and restore

Backups are encrypted with your backup password and include the database, every employee document and the file-encryption key. Keep copies on an external drive, away from this PC.

Sign in to the app as an Administrator on this PC first, then reopen this page.

Status

Backup password

Needed to open a backup on another PC. It is never stored and cannot be recovered: write it down and keep it somewhere safe. Changing it does not change older backups — they still open with the password they were made with.

Back up now

Daily backup

While the app is running it backs up once a day into the folder below (subfolder scheduled) and keeps the newest copies.

Restore

The backup is checked completely first. The current data is replaced when the app next starts, and kept in a pre-restore folder inside the data folder.
